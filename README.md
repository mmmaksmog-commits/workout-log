# 🏋️ Тренировки

**Журнал силовых тренировок с личными рекордами и графиком прогресса.**

### ▶️ [Открыть](https://mmmaksmog-commits.github.io/workout-log/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Каталог упражнений по группам мышц и свои упражнения
- Подходы с быстрыми кнопками ±2,5 кг и ±1 повтор
- Подстановка подходов с прошлой тренировки
- История тренировок с тоннажем
- Личные рекорды и график расчётного 1ПМ (формула Эпли) на SVG

## Стек

JavaScript, SVG-графики без библиотек, localStorage. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/workout-log.git
cd workout-log
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
